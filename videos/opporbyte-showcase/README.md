# Editable Opporbyte film

The website plays an encoded 35-second film with narration, original music and
transition sounds embedded together. This directory contains its deterministic
Three.js/Canvas authoring source and separate audio stems. Landscape and portrait
have their own composition; the website chooses by viewport aspect ratio and
shows the entire frame.

## Files and credits

- `film.mjs` and `index.html`: editable animation and preview controls.
- `assets/discover-*.png`: captures of the real local discovery demo using
  fictional examples. Only the development-tools overlay was hidden.
- `assets/card-textures.mjs`: generated from the existing frontend texture source.
  Resume and tracker objects are illustrative feature previews.
- `assets/voice-1.mp3` through `voice-7.mp3`: the approved script, generated by Fish
  Audio with Sarah after explicit user authorization. 524 package credits total.
- `make-audio.py`: seeded original score, sound effects, voice fitting and ducking.
  `score.wav`, `voice.wav`, `effects.wav`, and `mix-normalized.wav` are local stems.
- `BRIEF.md` and `manifest.json`: storyboard, source and narration provenance.
- `qa/`: selected frames and deterministic seek-versus-sequence checks.
- `../../frontend/public/films/`: final MP4s, posters, English WebVTT and encoded
  verification reports. No external audio requests are needed for playback.

Three.js is supplied under its retained MIT license. Inter and Space Grotesk
font licenses are retained in `assets`. The renderer was adapted from the local
Motion skill's direct-render script. Media has not been published to GitHub.

## Reproduce

Use Node.js 24 (for `stripTypeScriptTypes`), installed `frontend` dependencies,
Python with NumPy, FFmpeg with libx264/AAC, and `playwright-core` with an installed
Edge/Chrome browser. Run commands from this directory. Node may resolve
`playwright-core` locally; otherwise pass its node_modules directory explicitly.
No frontend package changes or provider calls are needed to render again.

```powershell
# Set these to your installed runtime paths.
$filmFfmpeg = 'C:/Users/adars/.bun/bin/ffmpeg.exe'
$filmPython = 'C:/Users/adars/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe'
$filmModules = 'C:/Users/adars/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules'

node prepare-assets.mjs
$env:OPPORBYTE_FFMPEG = $filmFfmpeg
& $filmPython make-audio.py

# Source preview is a silent animation editor; listen to mix-normalized.wav
# separately or play the encoded MP4 to hear the synchronized soundtrack.
node render-code-video.mjs --project . --mode preview --port 5273

node render-code-video.mjs --project . --mode qa --out qa/landscape --times 0,3,7,12,17,22,28,34 --fps 30 --playwright-root $filmModules
node render-code-video.mjs --project . --mode qa --format vertical --out qa/portrait --times 0,3,7,12,17,22,28,34 --fps 30 --playwright-root $filmModules

node render-code-video.mjs --project . --mode video --out ../../frontend/public/films/opporbyte-landscape.mp4 --overwrite --audio assets/mix-normalized.wav --fps 30 --crf 20 --ffmpeg $filmFfmpeg --playwright-root $filmModules
node render-code-video.mjs --project . --mode video --format vertical --out ../../frontend/public/films/opporbyte-portrait.mp4 --overwrite --audio assets/mix-normalized.wav --fps 30 --crf 20 --ffmpeg $filmFfmpeg --playwright-root $filmModules

node verify-film.mjs ../../frontend/public/films/opporbyte-landscape.mp4 $filmFfmpeg
node verify-film.mjs ../../frontend/public/films/opporbyte-portrait.mp4 $filmFfmpeg
```

Run exports separately on a busy machine. `--frame-timeout 120000` can raise
the per-frame bound without changing the animation. Output is H.264 yuv420p,
30 fps, AAC stereo at 48 kHz, with fast-start MP4 metadata for browser playback.
The verification script fully decodes, counts frames, measures audio and checks
streaming metadata. Its checks do not establish perceptual listening quality.
