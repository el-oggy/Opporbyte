# Opporbyte 3D revision

The first hero rendered real geometry but its shallow card edges, frontal camera,
unlit labels and understated movement did not communicate enough depth.

Keep the approved cream/ink/orange/cyan/white palette, Space Grotesk and Inter,
left-aligned headline and both CTAs. Keep the original short hero-to-section scope.
Use the orange core as the single memorable object: a thick ceramic O with a dark
recessed mechanical inner wall and a restrained cyan seam. Place beveled UI slabs
around it in three depth layers. A soft physical floor shadow anchors the object.

```text
wordmark                    navigation             get started

Your job hunt.                 job slab behind
Finally in                  sculptural O / dark cavity
one place.             resume in front       status at side
description                      cyan match capsule
actions                          perspective control

scroll cue                 Discover -- Connect -- Organize
```

The camera and objects rotate through a modest arc while scroll gathers the
objects into a dimensional miniature workspace. At rest, two or more side faces
must remain clearly visible. A small perspective control gives an immediate,
keyboard-accessible way to examine the scene. Mobile gets its own framing and
three objects; reduced motion gets a frozen sculptural pose and no pinning.

1. Install the existing global libraries without overwriting existing skills;
   create and validate the custom 3D skill and its natural-language routing.
2. Implement deterministic camera/core/card poses, stronger extrusion, lit card
   faces, layered core construction, soft shadows, and perspective interaction.
3. Inspect actual browser frames and refine composition before claiming success.
4. Run lint, types, reversible-pose tests, build, and browser checks covering
   navigation, responsive layout, reduced motion, scroll reversal and fallback.
5. Save evidence and handoff, commit locally, keep GitHub untouched.
