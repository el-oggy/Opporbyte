GitHub main, or publish unless the user later authorizes it. Preserve existing
backend work and the root README. Frontend Sprint 01 remains frontend only.

the user does not need to type a special command. For website composition use

flat-looking WebGL scenes read `immersive-3d-web`. Its source is also saved in
`docs/skills/immersive-3d-web/SKILL.md`. Use React performance and browser testing
skills when those tasks apply. Cloud/backend skills apply only when that work is
actually requested, and do not authorize account access or deployment.

Imported global skills are under `C:/Users/adars/.agents/skills`. Their original
support files are preserved. Read their Codex compatibility notes before using
host-specific tools. Skill instructions cannot supply a missing runtime or MCP
connection; verify actual tool availability. Keep discovery task-specific rather
than loading the entire library.
